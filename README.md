# Site N.E.K.O - Anomaly Database

> *An independent anomaly documentation and archival system.*

## What is N.E.K.O?

N.E.K.O is a fan-made project inspired by the SCP Foundation. It documents anomalies, maintains records, and provides a searchable database interface.

This is the public-facing archive. Documentation is complete and accessible to authorized personnel.

---

## Actually, What is N.E.K.O?

N.E.K.O is an independent anomaly documentation project that catalogs interesting entities. Think of it as the SCP Foundation, but with a very specific approach: every anomaly deserves to be documented with personality and charm.

The goal is to transform mundane technical records into something more engaging. To find the humanity—or whatever passes for it—in things that don't officially have feelings.

## Deeper Lore

There are administrative documents. Archive records. References to procedures and classifications that exist elsewhere.

Names appear in lists:
- M.I.R.E
- CPU-chan
- Ruka Katori
- Ren Takahashi
- The Purring Cassette
- Lilith
- Others marked [REDACTED] or [DATA NON-RECOVERABLE]

Some entries are marked "resolved." Some are marked "unconfirmed." Some have no status at all.

There's a concept called "resolution." Not containment. Resolution.

There are threat classifications: Petal, Bloom, Thorn, Fang, Eclipse, and beyond.

There are administrative notes about "emotional suppression protocols" and "behavioral contradictions."

There are references to personnel who are no longer part of the record.

If you're curious about what Site N.E.K.O really is, the documentation exists. It's just not all here. Not yet.
